# Sistema-Distribuido-de-An-lisis-de-Audio-con-Visualizador-F-sico-P2-SO
El proyecto es un sistema distribuido que analiza archivos de audio WAV y muestra los resultados en un visualizador físico. El usuario deja un archivo WAV en el nodo maestro del clúster, y el sistema se encarga de cifrarlo, repartirlo entre los nodos trabajadores, analizarlo y al final mostrar el resultado en hardware.
